# v6_hom — 当前版本（`model/` 与之相同）

## 改动

`a_t` 从跨时间递推改为**逐 token 编码**：每个位置从 `a = 0` 出发，在全局 7 系数定律下
松弛 `n_relax` 步。同时把固有时间乘到极分解的两个因子上。

## 它说明了什么

若 `a_t` 由 `a_{t-1}` 递推而来，记忆有两条通路：`a` 的非线性动力学，与 `Z` 的连乘。
`v5_tau` 的数据显示优化会集中到较省力的那条——`nocompose`（连乘被删掉）在训练长度上
仍有 0.995。

改为逐 token 编码后，`nocompose` 不再有任何跨时间通道，在 `window=1` 下必须落回随机；
`full` 则只能通过乘积保存跨位置的信息。

## 结果

S₃ 群词问题，训练长度 16：L=256 仍为 1.000，L=1024 为 0.990，L=2048 为 0.916。
读出清零后每个长度都退回随机。`nocompose` 在 S₄ 与 A₅ 上低于随机。
完整数据见 [`docs/EVIDENCE.md`](../../docs/EVIDENCE.md)。

## 局限

`k = 8` 只能忠实嵌入阶数不超过 8 的置换表示。S₄（24 阶）外推约 4 倍，A₅（60 阶）约 2 倍。
失效方式为退化到随机，不是系统性答错。
