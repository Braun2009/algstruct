# v3_boot — 读出接口的初始化

## 改动

`AlgebraState.out` 从零初始化改为小随机（`std = out_init = 3e-3`）。

## 它说明了什么

零初始化使训练起点精确等于 `off`，这是有价值的性质：两个臂只差结构流。但同时，
结构路径第 0 步的贡献为零，它的梯度不携带关于任务的信号。

在 `window = 1`（跨位置只能走状态）下这两件事叠加的结果是全体停在均匀解：
4000 步后 `loss = 1.790 = ln 6`，四个臂的 `flip` 全为 0。这条路径需要从一开始就能被
训练。小随机初始化保留了"起点接近 `off`"，同时让梯度有对象。

`verify.py` 的 `init_behaviour` 检查对两种初始化都覆盖：`out_init = 0` 时 `full` 与
`off` 的输出完全相同；`out_init > 0` 时结构路径在第 0 步即活。
