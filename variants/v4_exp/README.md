# v4_exp — 指数映射替代截断 Cayley

## 改动

```python
r = cayley(skew * scale)     # 旧：||skew||_F <= 1.2 → 单步最大转角 46°（a_limit=1 时 39°）
r = torch.matrix_exp(skew)   # 新：精确 SO(k)，处处光滑
```

## 它说明了什么

`Cayley` 在 `‖skew‖ = 2` 处有奇点，因此必须有截断；截断又限制了单个 token 能表达多大的
旋转。S₃ 含二阶元素（180° 对换），39° 的上限使它在单步内不可达，只能靠多步累积，
而多步累积的东西在序列长度变化时不再成立。

`matrix_exp` 作用于反对称矩阵时处处光滑、无奇点，`‖skew‖_F = √2·π ≈ 4.44` 处即可达到 180°，
因此 `a_limit = 5.0` 足够覆盖。顺带消除了 `sqrt` 在零点处的导数问题。

## 局限

单步可达 180° 只解决了"能否表达"，没解决"记忆存在哪"。
在 `group_state` 上准确率仍停在 0.177。
