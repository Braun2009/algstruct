# Algebraic Structure Stream

一个因果序列模型：语义流做聚合，结构流做组合，两者在一个表示（模作用）处接触。

**关键词**：非交换复合 · 矩阵值状态 · 部分逆 · 模作用 · 李群指数映射 · 固有时间 · 长度外推 · 状态跟踪 · 群词问题

## 摘要

多数序列模型把"记住什么"编码成向量，而向量的更新只能加和，因此"先做 A 再做 B"
与"先做 B 再做 A"没有区别。这不是容量差异，是类型不匹配：聚合的类型是**多重集 → 向量**，
结构的类型是**自由幺半群的元素**。把后者交换化之后，能看见的只剩下"净深度"，
而"谁配谁"落在交换化的核里，从原理上不可见。

本模型把跨位置的记忆放进一个 `k × k` 矩阵的**有序乘积**
`Z_t = A_t Z_{t-1}`：乘积不交换，次序因此进入状态。单步因子是 `A_t = R_t P_t`——
旋转乘收缩——所以它不是等距的，条件数可以很大，这就是部分逆的来源。
默认只让旋转累积（`Z_t = P_t · prefix(R)`）；把收缩放进连乘会让长序列上的信号被压平。

语义侧只在一个地方与它接触：矩阵通过左乘作用在一个单独划出的 `k · q` 维空间上，
结果经接口送回残差流。左乘是一个表示，`ρ(Z_2 Z_1) = ρ(Z_2)ρ(Z_1)`
精确成立，所以组合在传输中不被抹平。

编码是逐 token 的：每个位置在全局 7 系数定律下产生自己的局部生成元，没有跨位置的递推。
这一约束让消融具有判别力——删掉连乘，长程记忆必须随之消失，实测确实如此。

在群词问题上（状态为若干群元素的有序乘积），只用长度 16 训练：S₃ 在长度 2048 上仍有 0.92，
而全注意力基线在长度 64 就退回随机；把结构读出清零，每个长度都退回随机。

## 与相关工作的分野

矩阵状态不是新东西：线性注意力、状态空间模型、矩阵状态 RNN 都沿时间乘矩阵。
差别在这三处：

| | 常见的矩阵状态 | 本模型 |
| --- | --- | --- |
| 递推式 | `Z_t = A_t Z_{t-1} + b_t`，**有注入** | `Z_t = A_t Z_{t-1}`，**无注入** |
| 内容怎么进状态 | 被加进状态 | 只改写生成 `A_t` 的**定律** |
| 读出 | 与查询做内积（检索） | 模作用 `ρ(Z)s`（施加） |

有无注入不是风格问题，它可以算：把含注入的前缀乘积展开，若门控系数彼此可交换，
那么乘积项只依赖系数的**多重集**，与次序无关。次序只留在写入项的权重里。
换句话说，那一类状态记的是"什么出现过"，不是"以什么次序发生"。

内积读出同理：它把"先转再压"和"先压再转"化成同一个数。左乘不会——
`RP ≠ PR`。

细节、以及与等变网络、神经符号、生成元辨识（SINDy / port-Hamiltonian）的区别、
**本文不构成比较的地方**，见[与相关工作的分野](docs/RELATED.md)。

## 三条判断

一、**结构不是被读出的内容，而是被施加的变换。** 判据是状态在序列连接下同态：
`state(u · v) = act(state(v), state(u))`。聚合能重演结构，
不能替你带住它。

二、**结构的可逆是单边的、部分的。** `pq = 1` 但 `qp ≠ 1`。pop 是部分函数，
它的"未定义"正是深度信息的载体。所以收缩项必须在（否则状态始终良态），又不能累积
（否则长序列上乘积被压平）。

三、**必要性优于容量。** 能被忽略的旁路一定会被忽略。结构若只是并行的一路，
它在原理上就注定闲置，所以它必须在因果链上。编码逐 token 是同一件事的另一半：
跨时间的信息因此只剩乘积一条通道，删掉它，长程记忆就必须消失。

## 一次前向

```text
h      = 语义块(h)                        注意力 + RoPE + MLP
d_t    = W_d · LN(h_t)                    语义 → 结构，唯一入口（源项）
τ_t    = dt · σ(w_τ · LN(h_t))            固有时间，空操作为 0
a_t    = relax(a=0, d_t)                  逐 token，无跨时间递推
R_t    = exp(τ_t · skew a_t)              精确正交，‖R‖₂ = 1
P_t    = exp(τ_t · (sym a_t − λmax I))    谱在 (0, 1]
Z_t    = P_t · prefix(R)                  连乘，非交换
s      = W_s h_t                          接口：语义 → 结构空间
h_t   += W_o · ρ(Z_t, s)                  接口：结构空间 → 语义
```

## 它能做什么

群词问题：状态是若干群元素的**有序**乘积，训练长度只有 **16**。

| 群 | 模型 | L=16 | L=64 | L=256 | L=1024 | L=2048 |
| --- | --- | --- | --- | --- | --- | --- |
| S₃（6 阶） | 全注意力基线 | 0.50 | 0.25 | 0.19 | 0.17 | 0.17 |
| S₃ | **本模型** | **1.00** | **1.00** | **1.00** | **0.99** | **0.92** |
| S₃ | 本模型，读出清零 | 0.21 | 0.18 | 0.17 | 0.17 | 0.17 |

只在长度 16 上训练，外推到 **128 倍**长度仍有 0.92。把结构读出清零，每个长度都掉回随机。
[完整数据](docs/EVIDENCE.md) 含 S₄（24 阶）、A₅（60 阶，非阿贝尔单群）与消融。

## 在 CPU 上运行

```text
git clone https://github.com/Braun2009/algstruct.git
cd algstruct
python -m pip install -r requirements.txt
python -m examples.forward
```

示例随机初始化一个小模型，输入两条各含 8 个事件的序列。每个事件有 4 个离散字段，
取值范围 0 到 31。无需下载数据或权重。

```text
arm=full
events: (2, 8, 4)
logits: (2, 8, 32)
structural stats: {..., 'z_ratio': 0.8829, 'tau_mean': 0.4973, ...}
```

在自己的程序里：

```text
import torch
from model import AlgebraConfig, AlgebraModel

cfg = AlgebraConfig(width=64, layers=2, state_layers=(1,), k=4, q=16)
model = AlgebraModel(cfg, vocab=32).eval()
events = torch.randint(32, (2, 8, 4))
with torch.inference_mode():
    logits = model(events)      # 每个位置 32 个分数
```

## 检查构造性质

```text
python verify.py
```

9 组数值检查：`ρ` 的同态性与非交换性、`‖R‖_2 = 1` 且 `det R = + 1`、`‖P‖_2 ≤ 1`、
`τ = 0` 时 `Z` 精确等于单位阵、`tr(a) = 0`、沿长度的范数界、
**`a` 确实无跨 token 递推**、RoPE 的相对位置性质、各臂的梯度位置。

## 四种配置

| `arm` | 读出所用的矩阵 | 比较的因素 |
| --- | --- | --- |
| `full` | 截至当前位置的有序乘积 | 完整结构流 |
| `nocompose` | 仅当前的 `A_t` | 去掉累积；实测三个群上全部退回随机 |
| `nodrive` | `A_t = I`（驱动为零） | 切断语义输入，`ρ(I,s) = s` 退化为恒等作用 |
| `off` | 无结构读出 | 只运行语义主干 |

`compose_mode` 决定收缩因子是否进入连乘：`'rot'`（默认，`P_t·prefix(R)`）与
`'full_ap'`（`prefix(R·P)`，含部分逆的幺半群）。后者在长序列上会退化，见[实测](docs/EVIDENCE.md)。
