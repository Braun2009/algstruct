# 与相关工作的分野

[项目首页](../README.md) · [思想](PHILOSOPHY.md) · [设计](DESIGN.md) · [张量与参数](MODEL_MAP.md) · [实测](EVIDENCE.md)

## 摘要

许多方法都让状态变成矩阵，也都会沿时间做乘法。分野不在形状，而在**乘积里有没有注入项**、
以及**状态是记忆容器还是算子**。这一页说明技术栈上的重叠、以及问题设定上的差别，
并写明本文的结论在哪些方面不构成比较。

**关键词**：线性注意力 · 状态空间模型 · delta 规则 · 注入项 · 群等变 · 神经符号 ·
模式库与路由器 · 生成元辨识

## 一、先说重叠

以下这些技术在这里都用得上，而且都不是本文提出的：

| 技术 | 出处 | 本模型里的位置 |
| --- | --- | --- |
| 矩阵值递推状态 `Z_t = A_t Z_{t-1}` | 线性注意力一族、矩阵状态 RNN | 计算一步 |
| 逆矩阵 / 正交参数化 | 正交 RNN、unitary RNN | `R = exp(τ skew a)` |
| 极分解拆出旋转与收缩 | 经典矩阵分析 | `A = RP` |
| 时间常数与松弛动力学 | 连续时间 RNN、神经 ODE | `a` 的局部生成 |
| 生成元系数作为可学对象 | SINDy、Hamiltonian / port-Hamiltonian NN | 7 个全局系数 |
| 状态跟踪任务（A₅、S₅ 等） | 状态空间模型文献 | 本文用群词问题作判据 |

所以"把状态写成矩阵"不构成本文的差别。差别在下面几点。

## 二、注入项：最实质的一条

大多数带矩阵状态的模型，递推里有一个**注入项**：

```text
Z_t = A_t Z_{t-1} + b_t
```

delta 规则一类的更新把 `b_t` 换成"写入误差的修正"，形式更精致，但仍是注入：
内容被**加进**状态。

加法进入状态会带来一个可以算出来的后果：把前缀乘积展开，

```text
Z_t = (∏_{r ≤ t}a_r) Z_0 + Σ_s(∏_{r>s}a_r)b_s
```

若 `a_r` 是标量（或彼此可交换），第一项只依赖系数的**多重集**，与顺序无关；
顺序只通过 `b_s` 的权重进入。也就是说，标量门控的线性注意力在结构上等价于
按位置加权的求和——它能"记住什么出现过"，不能"记住以什么次序发生"。

本模型没有注入项。内容进入结构的唯一通道是**改写定律**：

```text
da/dt = −∇V(a) − D(a) sym(a) − Ω(a) skew(a) + d_t,    d_t = W_d h_t
```

`d_t` 进的是 `da/dt`，不是 `Z`。于是 `Z` 保持为纯粹的复合：

```text
Z_t = A_t A_{t-1}…A_1, Z_0 = I
```

这不是为了更简洁。它让"删掉连乘，长程记忆必须消失"成为可检验的陈述——
实测中该消融在三个群上全部退回随机。

代价是清楚的：没有注入，状态只能通过参数化地改变**怎么转**来表达内容，
而不能直接"写一个值进去"。本模型因此在检索类任务上不占优势，也不以那类任务为目标。

## 三、状态是记忆容器，还是算子

这条分野决定了读出怎么写。

| | 状态是记忆容器 | 状态是算子 |
| --- | --- | --- |
| 状态里的东西 | 若干键值对的压缩 | 一个待施加的变换 |
| 读出 | 与查询做内积：`qᵀZ` | 模作用：`ρ(Z)s = Z s` |
| 组合在读出后 | 被内积抹平 | 保留：`ρ(Z_2 Z_1) = ρ(Z_2)ρ(Z_1)` |
| 次序 | 只通过写入的权重进入 | 直接改变作用的结果 |

内积是一个标量化操作。它把"先转 90° 再压扁"和"先压扁再转 90°"都化成同一个数，
只要两个因子被加权的顺序在统计上对称。左乘不是：`RP ≠ PR`，
两种顺序给出不同向量。

所以本模型的读出是作用而不是检索。这也解释了为什么它不做注入：一旦允许把值写进状态，
读出就自然退化为内积检索，作用这一层就没有内容了。

## 四、与注意力：互补，不是替代

注意力的强项是**重演**：给定一个前缀，重新计算它的表示。代价是每个位置都要重看前缀。

本模型把跨位置的记忆压缩进一个 `k × k` 的算子，代价是它只能表达**可复合**的结构。

两者在类型上不同：聚合对位置可交换，组合不可交换。实测也支持这种分工——
同时开启注意力与结构流时，训练长度内的准确率更高，但外推到长序列时低于纯结构流。
注意力提供了在训练分布内更省力的通路，而那条通路不外推。

## 五、与"模式库 + 路由器"

若结构被写成值（系数、核、逐点的场），那么"这个任务需要哪种模式"只能表达成
"取哪一组数"。模式的数量由基的大小决定，选择方式必然是**先展开成基，再学一个门控去挑**。

矩阵不同。`gl(k)` 里的元素有乘法、有部分逆，非交换性是可测量的量。
更关键的是 `D` 与 `Ω` 写成**随状态变的场**：

```text
D(a) = d_0 + d_1‖a‖², Ω(a) = ω_0 + ω_1‖a‖²
```

一个固定系数集因此可以同时包含耗散区与注能区。于是"用哪种模式"不再是门控做出的选择，
而是**状态在地形上的位置**。

一个可检验的推论：既然是场，那么存在闭轨（注能区与耗散区的分界）。这是"多模式"与
"一个模式"在行为上的区别，而不是在参数表上的区别。

## 六、与群等变网络

等变网络把**给定的**群对称性写进层里：固定群、权重共享、约束卷积核。群是前提。

本模型不给群。`a` 是 `gl(k)` 里的任意元素，它生成的变换不必属于任何预设群；
"这个任务是什么代数类型"不是架构师声明的，而是由状态的轨迹承载，逐 token 变化。
7 个系数全局共享，责任在"定律"，类型在"状态"。

代价是不保证任何对称性。收益是它不预设任务属于某个已知群。

## 七、与神经符号

神经符号把结构写成外部符号系统：解析、类型、可微逻辑、程序归纳。代数结构是手写的语法。

本模型全程连续：`a ∈ gl(k)`，没有离散符号，没有任务标签，没有手写文法。
非交换、部分逆这些性质来自矩阵乘法的性质，而不是来自一条规则表。

一个直接的后果是失效方式不同：符号系统在解析失败处硬崩，这里退化到随机。

## 八、与生成元辨识（SINDy、port-Hamiltonian 等）

这一支的问题是：给定一条轨迹，能否恢复出生成它的结构（`L`、`M`、能量、支撑）。

本模型与它共享参数化形式，但问的是另一个问题：**一个序列模型内部，逐 token 生成的
算子如何沿时间复合**。`V` 在这里不是为了拟合物理，而是为了让每个 token 的局部生成元
成为一个有界响应的松弛——它给出时间常数、平衡振幅与稳定性，三者都是可测的设计量。

所以引用关系是：形式上的来源可以追溯到这一支；问题设定不重叠。

## 九、不构成比较的地方

必须写明，否则容易被误读：

1. **没有在标准状态跟踪套件上做比较。** 本文的判据是群词问题的长度外推与读出消融，
   不是 A₅ / S₅ 任务的最优准确率。更强的状态空间模型在这些任务上的报告数字
   通常优于本模型在短长度处的表现。
2. **外推范围受表示容量限制。** `k = 8` 下 S₃（6 阶）外推 128 倍，S₄（24 阶）约 4 倍，
   A₅（60 阶）约 2 倍。这是可解释的失败（`gl(8)` 无法忠实嵌入 60 阶群），
   但不构成对更大 `k` 的证明。
3. **不以检索类任务为目标。** 没有注入项意味着状态不是键值存储。语言建模一类的
   稠密检索任务不在本文的评估范围内。
4. **规模小。** 实验在 `w = 256`、4 层上进行，没有做规模律。

## 十、一句话

与主流矩阵状态模型的区别不在"状态是矩阵"，而在**乘积里没有注入项**、
以及**读出是作用而不是检索**。这两条一起，才能把"次序"从统计加权里拿出来，
放到可以被删掉、被检验的位置上。
