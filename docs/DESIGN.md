# 结构流的设计

[项目首页](../README.md) · [思想](PHILOSOPHY.md) · [张量与参数](MODEL_MAP.md) · [实测](EVIDENCE.md) · [与相关工作的分野](RELATED.md)



## 摘要

模型在同一条事件序列上并行运行两条流：语义流按注意力聚合，结构流把每个位置生成的
变换沿时间连乘。两条流只通过一个模作用接触：矩阵左乘在一个单独划出的 $k\cdot q$ 维空间上。

本文按"编码 / 计算 / 作用"三问分述：每个 token 产生什么变换、这些变换如何组合、
组合结果如何作用于语义。三件事各自张量形状与不变量见[张量与参数](MODEL_MAP.md)，
为什么这样选择见[思想](PHILOSOPHY.md)。

**关键词**：局部生成元 · 李群指数映射 · 配对极分解 · 固有时间 · 前缀乘积 · 模作用 · 接口

两条流。语义流做聚合：注意力、加权、可平均。结构流做组合：矩阵乘法、非交换、有部分逆。
两者只在接口处接触——结构元素作用在一个单独划出的空间上，结果送回语义侧。

这份文档说的是模型**是什么**。坏了怎么发现、拿什么数判断，属于[实测](EVIDENCE.md)。

## 结构不能是值

结构写成系数、核函数、逐点的场，都试过。共同问题是：**值没有乘法**。

一个值能加法、能缩放、能被网络读出来，但没有 `ab` 和 `ba` 的区别，也没有逆。
没有乘法，就没有"先做 A 再做 B"和"先做 B 再做 A"的差别；没有逆，就没有
"这一步能不能撤回"。于是"这个任务用的是哪种模式"只能表达成"系数取哪一组数"，
模式的数量由基的大小决定，选择方式必然长成模式库加路由器。这不是实现得不好，
是"结构＝值"这个前提的直接结果。

$$a\in\mathfrak{gl}(k)\ \text{或}\ k\times k\ \text{实矩阵},\qquad a\ \text{有乘法，有部分逆}$$

## 三件事分开

同一个词同时指三件事，讨论就没有落点。所以：

| | 是什么 | 谁决定 |
| --- | --- | --- |
| **编码** | 每个 token 生成什么样的变换 | 7 个全局系数 + 语义驱动 |
| **计算** | 这些变换怎么组合 | 架构固定：沿时间连乘 |
| **作用** | 怎么和语义向量接触 | 架构固定：`ρ(Z, s)`，接口可学 |

## 编码：逐 token，没有跨时间递推

对每个位置独立地，从 `a = 0` 出发，在全局 7 系数定律下松弛 `n_relax` 步：

```text
C    = aaᵀ − aᵀa
V(a) = v₂ tr(a²) + v₃ ‖a‖²_F + v₄ ‖C‖²_F
D(a) = d₀ + d₁ ‖a‖²_F
Ω(a) = ω₀ + ω₁ ‖a‖²_F

Δa   = −∇V(a) − D(a) S − Ω(a) K + d_t,        S = sym(a),  K = skew(a)
a    ← a + dt·Δa / (1 + ‖Δa‖_F / step_limit)
a    ← a − tr(a) I / k                        (无迹投影)
a    ← a · min(1, a_limit / ‖a‖_F)            (球面投影)
```

`d_t = W_d · LayerNorm(h_t)` 是**源项**，只从这个 token 来。

**没有跨 token 的递推。** 这一点是机制性的，不是简化。若 `a_t` 由 `a_{t-1}` 递推而来，记忆就有两条通路：
`a` 自己的非线性动力学，以及 `Z` 的连乘。两条通路不等价，优化会集中到较省力的那条。

`a_t` 只依赖 `h_t`，于是跨时间的信息只能活在不交换的乘积里。这一约束让消融具有
判别力：删掉连乘，长程记忆必须随之消失。

## 固有时间：τ 由内容给出

```text
Δτ_t = dt · σ(w_τ · LayerNorm(h_t)) ∈ (0, dt)
```

ODE 与李群积分都写在固有时间 τ 上，而不是 token 编号：

```text
da/dτ = −∇V(a) − D(a) sym(a) − Ω(a) skew(a) + d_t
dZ/dτ = skew(a) Z
```

离散化时**两个因子都乘 τ**：

```text
R_t = exp(Δτ_t · skew(a_t))                    精确正交，‖R‖₂ = 1
P_t = exp(Δτ_t · (sym(a_t) − λmax I))           谱在 (0, 1]，‖P‖₂ ≤ 1
```

当 `Δτ_t → 0`（填充、空操作），`R_t = P_t = I`，于是 `A_t = I`、`Z_t = Z_{t-1}`：
结构流对插入任意多空 token **严格不变**。

真实序列里真正改变结构的事件只占少数：`group_state` 的 128 个位置中约 7 个有效。
固定步长下，每个噪声位置都会推进一次 ODE 并乘一次矩阵，序列的填充长度因此进入结果。

τ 需要同时作用于两个因子。若只作用于 `R`，`τ → 0` 时 `P` 仍在收缩 `Z`，
空操作不再严格无损。

## 计算：连乘，不走注意力

| 注意力做的事 | 对代数做了什么 |
| --- | --- |
| 对位置做加权平均 `Σⱼ αⱼ vⱼ` | 平均破坏乘法：`‾ab ≠ ā·b̄` |
| 分数是标量 `⟨q,k⟩` | 退化到域上，非交换性消失 |
| softmax 归一化 | 可逆性被归一化抹掉 |

$$\mathbf{Z}_t = \mathbf{A}_t \mathbf{Z}_{t-1},\qquad \mathbf{Z}_0 = I$$

前缀乘法用倍增扫描，`log₂(T)` 次 matmul。括号位置改变，因子次序不改变。

两种组合模式：

| `compose_mode` | 定义 | 性质 |
| --- | --- | --- |
| `rot`（默认） | `Z_t = P_t · prefix(R)` | 累积部分是等距的，`‖prefix(R)‖_F = √k` 恒成立；`P_t` 只作用一次 |
| `full_ap` | `Z_t = prefix(R · P)` | 含部分逆的幺半群，但 `P` 的收缩会累积 |

`full_ap` 在长序列上会退化：`z_ratio` 趋向 0，乘积被压平（见[实测](EVIDENCE.md)）。
默认 `rot`——`P` 是**逐位置的选择性**，不应成为**跨位置的累积收缩**。

**`P` 本身要留下。** 它是收缩，收缩不可逆，这正是"部分逆"的内容：
`push∘pop = 1` 但 `pop∘pop ≠ 1`。只让正交因子累积、把 `P` 整个删掉，`Z` 就永远是
正交的、永远可逆，`‖[a,aᵀ]‖` 也失去意义。所以 `P` 留下，但不进连乘。

由构造：`0 < ‖Z_t‖_F ≤ √k`。

`λmax` 在 float64 里算并 detach。初始化时 `a ≈ 0`，谱退化，`eigh` 会抛错或让反向
返回 NaN，而重复谱正是初始化的常态。移位必须等于 `λmax` 本身，不能用 `‖sym a‖_F`
这类上界：各向同性收缩会给出 `P = exp(−3|c|I)`，256 步之后 `Z` 精确归零。

## 作用：模作用

两个东西量纲不同，一个是矩阵，一个是向量，不能相加。让它们接触的规范方式是：

$$\rho(\mathbf{Z})\,s = \mathbf{Z}\,s,\qquad s \text{ 视为 } k\times q$$

`ρ` 是一个表示：`ρ(Z₂Z₁) = ρ(Z₂)ρ(Z₁)`，严格成立。它没有参数——作用的形式不学，
学的是作用在什么上。

**结构流有自己的状态空间。** 语义侧算出 `s`，`Z` 作用在 `s` 上，结果送回语义侧：

```text
h            (b, t, w)
  ├─ to_s ──► s (b,t,k,q)       语义 → 结构：接口，逐层
  │             │
  │             ├─ ρ(Z) ──► (b,t,k,q)     结构作用：Z 由 7 个全局系数沿时间生成
  │             │
  └─────────────┴─ out ──► h + …          结构 → 语义：接口，逐层
```

若把 `s` 直接取成 `h` 的 reshape，等于断言"残差流的第 i 段天然就是结构槽位 i"。
这个断言没有理由成立：残差流的基是语义侧自己长出来的，它优化的是聚合，不是组合。
接口 `W_s`、`W_o` 使得复合映射是

$$h \;\longmapsto\; W_o\,(\mathbf{Z}\otimes I_q)\,W_s\,h$$

当 `W_o ≈ W_s⁻¹` 时，这正是 `Z` 在语义空间的**共轭表示**——共轭不改 `Z` 的共轭类，
所以 `Z` 的代数身份（迹、谱、非正规度）在传输中保持不变。

**接口自由，算子不自由。** 中间那一层被钉死：`Z` 只有 `k²` 个数，由 7 个全局系数
沿序列生成，跨所有 `q` 块共享同一个 `Z`（`Z ⊗ I_q`）。这是它与一个自由线性变换的分界线。

`out` 取小随机初始化（`3e-3`）而非零。零初始化使起点精确等于 `off`，这一点有明确价值；
但结构路径第 0 步贡献为零，其梯度不携带关于任务的信号。小随机让路径从一开始即可训练。
两者的实测对比见[实测](EVIDENCE.md)。

## 全局定律，逐层接口

7 个系数**全局一组**，所有结构层共享。这是"一套生成元、多种模式"的最强版本：
定律收敛，适配发散。若每层一组，就有多套生成元，"一套定律长出一个动力学"就测不到了。

`k` 是代数的维数：这个算子能表达多复杂的重排。`q` 是每个分量的带宽。两者由接口解耦。

## 四条零散的守恒

| 量 | 约束 | 来源 |
| --- | --- | --- |
| `‖R‖₂` | = 1，`det = +1` | `exp(skew)`，`skew` 反对称 |
| `‖P‖₂` | ≤ 1 | `exp(sym − λmax I)` 的谱 |
| `‖Z_t‖_F` | ≤ √k | 次乘性；`rot` 模式下恒等于 `‖P_t‖_F √k / √k`，不随 t 衰减 |
| `ρ` 同态误差 | 0 | 左乘的定义 |
| `tr(a)` | = 0 | 每步投影 |

## 两条流各自算的东西

语义侧算二阶统计量内积 `⟨q,k⟩`，那是 `S` 上的**交换**双线性型；结构侧通过 `ρ`
作用过去，那是非交换的乘。两侧的计算方式在数学上就不同——不是工程折衷，
是两者性质的差别。

语义块对 `q`、`k` 施加旋转位置编码，`v` 不施加：被平均的量不能被旋转。
结构侧的位置由非交换连乘承载，不需要位置输入。两者因此是两条独立的顺序通道。
