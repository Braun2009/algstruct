# 结构流的设计

[项目首页](../README.md) · [张量与参数参考](MODEL_MAP.md)

在同一条事件序列中，有些问题只需要汇总已经出现的内容，有些问题还取决于操作的先后次序。这个模型让局部因果注意力处理前一种计算，同时为后一种计算提供显式的矩阵乘积。下面分别说明乘积的次序、每个因子的来源，以及连乘在数值上能保证什么。

## 次序怎样进入读出

考虑平面上的两个操作：`R` 将向量逆时针转 90°，`P` 保持横坐标并把纵坐标减半。从 `(1, 0)` 出发，两种次序得到不同的终点：

| 顺序 | 第一步 | 第二步 |
| --- | --- | --- |
| 先 `P` 后 `R` | `(1, 0)` | `(0, 1)` |
| 先 `R` 后 `P` | `(0, 1)` | `(0, ½)` |

这是乘法次序的例子，不是训练结果。在模型里，`Aₜ` 是第 t 个位置生成的矩阵；最新的因子从左边乘入，所以第三步的读出来自 `A₃ A₂ A₁`。对应到特征向量 `s` 上，先作用 `B` 再作用 `A`，得到 `A(Bs) = (AB)s`。这一关系也解释了为什么简单地平均 `A` 和 `B` 无法表达上表的两种结果。

[model/action.py](../model/action.py) 的 `rho` 给出了左乘的直接实现，可以单独用于向量。主模型采用另一种读出路径：它将整个乘积 `Zₜ` 展平，经可学习映射 `W_o` 加回语义主干。前向过程并不调用 `rho(Aₜ, hₜ)`。

## 输入怎样生成一步变换

每个结构层在一次前向开始时取 `a₀ = 0`、`Z₀ = I`。当前位置的语义向量通过带偏置的线性层 `to_drive` 生成矩阵 `dₜ`。下式中的 `a` 是上一步的状态，`S = (a + aᵀ)/2`，`K = (a − aᵀ)/2`，分别取对称部分和反对称部分。

```text
C    = aaᵀ − aᵀa
V(a) = v₂ tr(a²) + v₃ ‖a‖²_F + v₄ ‖C‖²_F
D(a) = d₀ + d₁ ‖a‖²_F
Ω(a) = ω₀ + ω₁ ‖a‖²_F

Δa   = −∇V(a) − D(a) S − Ω(a) K + dₜ
```

这里 `tr(a²)` 是矩阵平方 `a @ a` 的迹；`‖a‖²_F` 是所有元素的平方和。两者对一般矩阵并不相等。最后的四次项度量 `a` 与其转置交换的程度：它恰好在 `aaᵀ = aᵀa` 时为零。这只描述这一项，不决定整个势函数的极小点。

每个结构层有自己的七个标量系数，同一层内的所有位置共用它们。`D` 和 `Ω` 仍然可以随状态变化。例如取 `d₀ = −1, d₁ = 1`，当 `‖a‖_F` 穿过 1 时，`−D(a) S` 会从增强对称分量变为抑制它。单个分量变号并不足以推出完整动力学存在周期轨道。

积分时先将 `Δa` 除以 `1 + ‖Δa‖_F / step_limit`，再乘 `dt` 加到 `a` 上。最后减去 `tr(a) I / k`，得到无迹状态 `aₜ`。因此 `tr(a)` 在允许的状态上恒为零，势函数中不设线性迹项。

## 连乘的上界与代价

对更新后的 `aₜ` 再取对称部分 `S` 和反对称部分 `K`。实现先按 `skew_limit` 限制 `K` 的 Frobenius 范数，再构造两个因子：

```text
R = (I − K/2)⁻¹ (I + K/2)
P = exp(S − λmax(S) I)
A = RP
```

`R` 由 Cayley 变换得到。在精确算术下它是正交矩阵，因此保持向量长度。`P` 是矩阵指数；它沿第 i 个特征方向缩放 `exp(λᵢ − λmax)` 倍。所有缩放因子都介于 0 与 1 之间（含 1，不含 0）。于是每步的谱范数至多为 1，由范数的次乘性，整个前缀乘积也满足 `‖Zₜ‖₂ ≤ 1`。这个上界不约束语义主干或最终 logits 的范数。

即使每一步的最大奇异值都恰好是 1，也未必有一个方向能从头到尾保持长度。例如，连续两步分别取 `diag(1, ½)` 和 `diag(½, 1)`，乘积就是 `½ I`。重复这两步会让所有方向一起衰减。每个有限步的 `P` 在精确算术下仍然可逆；实际计算中，小奇异值可能低于浮点精度，导致早期信息难以恢复。因此，长序列的记忆能力仍需实测。

[AlgebraState.decompose](../model/algebra.py) 在不求梯度的分支中用 float64 计算最大特征值；若求解失败，就退回到 `‖S‖_F` 作移位。后者仍是上界，但此时 `P` 的最大特征值可以小于 1。实现先沿时间递推得到各步的 `aₜ`，再批量构造矩阵并计算前缀乘积。前缀扫描改变乘法的括号位置，不改变因子次序。

## 如何区分训练效果与结构性质

若要考察任务是否需要跨步复合，首先比较 `full` 与 `nocompose`。两者使用相同形状的参数、驱动和读出；后者仍生成各步的 `aₜ` 和 `Aₜ`，只移除了 `Aₜ` 之间的连乘。`nodrive` 回答另一个问题：当结构层收不到事件内容时，仅靠主干和常量读出能做到什么？`off` 则给出没有结构层的基线，其参数量也较少。

`a_var` 可用来观察状态是否随位置变化，`z_last` 可用来观察序列末端的乘积是否衰减。两者都不能代替任务指标；谱范数上界也只是对矩阵运算的保证。各统计量的范数、归约维度及多层行为见[实现参考](MODEL_MAP.md)。
